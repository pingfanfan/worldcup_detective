# 伤病观察员 · 2026 世界杯半决赛：法国 vs 西班牙

**我读了错题本，本次注意了以下教训：**

1. **「出席≠状态」**：名单上的人不等于满血输出。过去英格兰 James / Guehi / Rice 等伤病消息喧嚣但仍小胜挪威，说明必须区分「能出场」与「状态几成」，尤其关注后腰、中卫等关键位置的真实身体输出。  
2. **「淘汰赛低比分小胜是常态，必须预留加时/点球尾部概率」**：进入半决赛后对手质量接近，体能、伤病与黄牌累积会进一步压低节奏，90 分钟平局或加时出局都是合理尾部。  
3. **「55%–65% 小热门仍需设防」**：题干给出 Opta 超级计算机法国晋级 57.7% / 西班牙 42.3%，法国并非深盘稳赢，伤病/体能变量足以让小热门翻车。

## 一、法国伤情：后腰线亮起黄灯，中卫带伤硬撑

### 1. 姆巴佩（Kylian Mbappé）——脚踝小撞伤，自述无碍但“出席≠状态”
- 对摩洛哥 2-0 的 1/4 决赛中，姆巴佩第 77 分钟被换下，场边可见对脚踝冰敷。  
- 赛后他亲自表态：*“I have a minor ankle injury, but I'm completely fine”*，并强调换人是 precautionary，因为 Mateta 当时体能更好。  
- **我的判断**：嘴上说没事，但半决赛被提前换下+冰敷，爆发力与变向启动存在打折可能。这是黄灯，不是绿灯。  
- 来源：[Sports Mole](https://www.sportsmole.co.uk/football/france/world-cup-2026/news/any-reason-for-concern-mbappe-issues-injury-update-ahead-of-wc-semi-final_601011.html)、[RTE](https://www.rte.ie/sport/soccer/2026/0710/1582694-mbappe-dismisses-injury-fears-after-quarter-final-victory/)

### 2. 楚阿梅尼（Aurélien Tchouameni）——大腿/腹股沟，本场比赛最大 X 因素
- Sports Mole 将他列为 **Major doubt**，类型为大腿伤势，自 7 月 3 日训练受伤后已缺席最近两场。  
- Khel Now 报道称他因腹股沟问题“unlikely to return to the ongoing campaign”，但仍在争取及时复出。  
- 不过 Bolavip 援引 *L’Équipe* 记者 Damien Degorre 表示：*“His recovery is considered satisfactory, and he appears fit to start the match.”*  
- RotoWire 则把他标为 **game-time decision**，并指出他是法国防守型中场的锚，若状态不足，法国整条防线前的高压屏障会降级。  
- **我的判断**：多方消息冲突，最终状态待确认；即便首发，缺席两场后能否维持 90 分钟高强度对抗罗德里+佩德里的传控，是最大疑问。  
- 来源：[Sports Mole](https://www.sportsmole.co.uk/football/france/injury-news/injuries-and-suspensions/mbappe-tchouameni-kone-latest-france-injury-suspension-list-vs-spain_601068.html)、[Khel Now](https://khelnow.com/football/france-injury-news-ahead-fifa-world-cup-2026-semi-final-vs-spain)、[Bolavip](https://bolavip.com/en/world-cup/france-receive-good-news-ahead-of-2026-world-cup-semifinals-with-tchouameni-reportedly-back-vs-spain)、[RotoWire](https://www.rotowire.com/soccer/article/france-vs-spain-preview-predicted-lineups-team-news-tactical-analysis-2026-world-cup-semifinal-122319)

### 3. 科内（Manu Koné）——膝盖轻微不适，71 分钟被换下
- 对摩洛哥第 71 分钟因膝盖小问题+疲劳被换下，Sports Mole 列为 **Minor doubt**，认为换人更偏向预防性。  
- **我的判断**：如果楚阿梅尼无法首发，科内就要与拉比奥搭档双后腰；但他自己也有膝伤隐患，法国后腰双核同时亮黄灯。  
- 来源：[Sports Mole](https://www.sportsmole.co.uk/football/france/injury-news/injuries-and-suspensions/mbappe-tchouameni-kone-latest-france-injury-suspension-list-vs-spain_601068.html)

### 4. 图拉姆（Marcus Thuram）——小腿，预计替补
- Sports Mole 与 RotoWire 均列为 doubtful / game-time decision，但预测首发中没有他，德尚更可能继续用姆巴佩突前。  
- 来源：[Sports Mole 综合队报](https://www.sportsmole.co.uk/football/france/world-cup-2026/team-news/france-vs-spain-injury-suspension-list-predicted-xis--world-cup-2026_601095.html)、[RotoWire](https://www.rotowire.com/soccer/article/france-vs-spain-preview-predicted-lineups-team-news-tactical-analysis-2026-world-cup-semifinal-122319)

### 5. 于帕梅卡诺（Dayot Upamecano）& 萨利巴（William Saliba）——中卫线带伤训练
- Khel Now 报道：于帕梅卡诺脚痛，但预计不会让他缺席首发；萨利巴则一直受背伤困扰，已经错过多次训练，半决赛前训练也未现身。  
- Sports Mole 的综合伤停表没有把两人列为 doubt，但 Khel Now 明确提到他们缺席训练。  
- **我的判断**：中卫搭档若带伤作战，面对西班牙灵活的奥亚萨瓦尔、亚马尔与后排插上的奥尔莫/法比安，转身与对抗风险会被放大。  
- 来源：[Khel Now](https://khelnow.com/football/france-injury-news-ahead-fifa-world-cup-2026-semi-final-vs-spain)

### 6. 停赛情况
- **法国无停赛**。四强阶段黄牌已经清零，巴科拉、奥利塞、科内等原本累积黄牌者均可出战。  
- 来源：[Sports Mole](https://www.sportsmole.co.uk/football/france/injury-news/injuries-and-suspensions/mbappe-tchouameni-kone-latest-france-injury-suspension-list-vs-spain_601068.html)

## 二、西班牙伤情：边路深度受损，但核心框架基本 intact

### 1. 耶雷米·皮诺（Yeremy Pino）——肩锁关节扭伤，久疏战阵
- 小组赛末轮对乌拉圭时锁骨/肩锁关节扭伤（acromioclavicular sprain），并非最严重骨折。  
- Sports Mole 列为 **Minor doubt**，认为他可以出战法国，但已经连续 3 场未出场。  
- **我的判断**：能报名不等于能首发，更不等于能提供 90 分钟高强度突破；他更多是后手选择。  
- 来源：[Sports Mole](https://www.sportsmole.co.uk/football/spain/injury-news/injuries-and-suspensions/pino-williams-munoz-latest-spain-injury-suspension-list-vs-france_601071.html)

### 2. 尼科·威廉姆斯（Nico Williams）——大腿/腹股沟，替补复出

- 对比利时 1/4 决赛最后阶段替补登场，Sports Mole 认为他应可出战，但能否首发仍待定。  
- **我的判断**：他可以提供纵深冲击，但大概率从板凳开始；西班牙左路首发可能继续用阿莱克斯·巴埃纳。

## 四、综合评估：法国的结构性伤停风险更高

| 维度 | 法国 | 西班牙 |
|---|---|---|
| 核心伤病 | 楚阿梅尼（后腰，major doubt）、科内（后腰，minor doubt） | 佩德里（状态非最佳）、皮诺（久疏战阵） |
| 防线伤病 | 于帕梅卡诺（脚痛）、萨利巴（背伤） | 基本完整（波罗/库巴西/拉波尔特/库库雷利亚） |
| 锋线伤病 | 姆巴佩脚踝小撞、图拉姆小腿 | 亚马尔/奥亚萨瓦尔 intact，尼科·威廉姆斯替补可用 |
| 停赛 | 无 | 无 |
| 休息 | 多休一天 | 少休一天 |

- **法国的最大风险在后腰+中卫**：楚阿梅尼是法国由守转攻的第一拦截点，如果他无法首发或只能带伤踢，西班牙罗德里+佩德里/法比安的三角传递将更容易找到法国两线之间的空档。科内同样膝盖有恙，让双后腰深度打折。  
- **西班牙的最大风险在边路后手**：尼科·威廉姆斯与皮诺都不是首发刚需，但会影响德·拉·富恩特 60 分钟后变阵的锐度。  
- **姆巴佩“完全没事”听听就好**：他说 fine，但淘汰赛被提前换下+冰敷，面对库库雷利亚这种缠人型左后卫，第一步爆发力若有折扣，法国最锋利的转换武器会钝。  
- **天气与场地不是决定性变量**：空调球场抹平了法国/西班牙在湿热适应上的差异，不必过度渲染。

## 五、我的投票

**西班牙胜**

理由：法国后腰双核楚阿梅尼、科内与中后卫于帕梅卡诺、萨利巴均存在不同程度伤情或状态疑问，而法国要限制西班牙的传控渗透恰恰最依赖这些人的对抗与覆盖；西班牙核心框架相对完整，没有停赛，阵容健康度占优，因此从伤病与体能角度看，我投西班牙胜。
